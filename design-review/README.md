# WalletWise HTML design review

Open `index.html` in a modern browser. The review prototype is intentionally isolated from the Expo application and does not change runtime app behavior.

## Review controls

- Use **Emerald**, **Compare**, and **Purple** to switch color direction.
- Select any screen in the left navigation. There are 28 screen families and each one is rendered in both themes.
- Click controls inside the phone previews to move through the primary product flows.
- Use the month arrows on Transactions and Budgets to inspect the month-navigation treatment.
- Choose **Emerald** or **Purple** in the decision bar to save a preference in the browser's local storage.
- Use the fullscreen button for presentation mode. `Escape` exits it.

The prototype loads Manrope and Material Symbols from Google Fonts. The rest of the experience, including both approved WalletWise icon files, is local.
